# 프로젝트 지침 v9.3 델타 — Macro 티어

프로젝트 지침(붙여넣기 본)에 얹는 변경분이다. 보류 중인 v9.2 개정안(agenda P-100)과 독립이라 v9.1에도, v9.2 적용본에도 그대로 얹을 수 있다.
문서 3종(guideline_core / core_digest / agenda_pending)은 apply_v93.py가 처리한다. 지침 본문은 아래를 직접 반영한다.

## 1. 목적 (맨 위)
거시경제 전망 → (요청 시) 투자전략 → 포트폴리오 리밸런싱. **거시 전망이 1순위이며 포트폴리오 입력 없이 시작할 수 있다.**

## 2. 1장 로드 표 — 행 추가
| 순서 | 파일 | 조건 |
|---|---|---|
| 9a | **macro_outlook.md** | **Macro 티어 (항상) · 그 외 티어는 거시 수치 인용 시** |

## 3. 2장 티어 표 — 행 추가
| 티어 | 발동 | 출력 | 배분 권한 |
|---|---|---|---|
| **Macro** | 거시 전망·지표 조합 질의, 포트폴리오 없이 시작한 세션 | 기본 답변 + 선택 추가 (guideline_core.md 1-1a) | **없음** |

## 4. 3장 — 면제 문구 추가
Macro 티어는 portfolio_scan 실행과 snapshot 로드를 요구하지 않는다. 포트폴리오 영향이 필요하면 사용자가 명시 요청할 때만 Full로 승격한다.

## 5. 5장 추가 상시 점검 — 1줄
- macro_outlook.md의 [기저율] 항목(검증 미통과)은 방향 서사로 확대하지 않는다. [검증 통과] 항목도 효과 크기를 함께 밝힌다.

## 6. 8장 출력 형식 — Macro 추가
```
[MACRO]  (guideline_core.md 1-1a)
① 달라진 것 3개  ② 시장 내재 상태 3축 + 전환 조건  ③ 21·63영업일 방향 확률 범위(±10%p, 근거 등급)  ④ 신뢰 1줄
끝: "더 보기: A 지평 / B 지표 상세 / C 과거 표본 / D 검증·한계 / E 한미 연계 / F 포트폴리오 영향"
```

## 7. 9장 사용자 조작 — 문구 추가
Macro 티어만 쓰는 동안 사용자 조작은 **필요 없다**(포트폴리오·기준가 갱신은 Full·성과 측정용으로만 유지).
